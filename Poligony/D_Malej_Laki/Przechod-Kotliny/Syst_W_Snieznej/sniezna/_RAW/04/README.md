# Wielka Śnieżna — On Station i Kartow3

- **Status materiału:** częściowy
- **Pochodzenie danych:** Projekt „Małołączniak” w formacie On Station opracował i przekazał Dariusz Bartoszewski. Bolek.zip zawiera wcześniejszy projekt kartograficzny Wiktora Bolka, prowadzony w jego autorskim programie Kartow3.
- **Autorzy pomiarów:** Nieustaleni. W sekcji Przemkowe Partie pliku CDI Dariusz Bartoszewski, Rafał Mateja, Radosław Paternoga i Maciej Mieszkowski mają wpisaną rolę „Exploration” (wiersze 2445–2452).
- **Daty pomiarów:** nieustalone dla obserwacji terenowych
- **Data pozyskania:** 2011-10-03 (Malolaczniak.zip), data przekazania Bolek.zip nieustalona
- **Dodał do _RAW:** Codex na zlecenie Dariusza Lubomskiego, 2026-11-19
- **Licencja źródłowa:** CC BY-SA 4.0
- **Kompletność:** CDI obejmuje historyczne ciągi Wielkiej Śnieżnej. Trzy wydzielone pliki POM wykorzystano do uzupełnienia MAIN.SRV.

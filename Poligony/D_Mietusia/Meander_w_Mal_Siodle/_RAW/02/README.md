## Uwagi o lokalizacji

Według opisu autora pozycję GPS określono na grani około 3–4 m nad otworem; ekranowa dokładność wynosiła około ±4 m. Zdjęcia pokazują także wskazanie wysokości 1808 m, a wiadomość podaje 1801 m według Grodzickiego z zastrzeżeniem sprawdzenia. Nie utożsamia się tego punktu automatycznie ze stacją 0 ani nie zastępuje nim aktywnego fixu.

Odczyty i deklarowana dokładność urządzenia są dokumentacją historycznego przekazu. Nie stanowią niezależnego potwierdzenia geodezyjnego ani daty wykonania pomiarów podziemnych. Aktywne współrzędne otworów utrzymuje projekt GPS.

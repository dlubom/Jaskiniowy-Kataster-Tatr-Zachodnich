# Lod w Ciemniaku - paczka zrodlowa 01

- **Status materiału:** dostępny
- **Pochodzenie danych:** Pomiary Wielkopolskiego Klubu Taternictwa Jaskiniowego (WKTJ). Materiały przekazał Adam Łada.
- **Autorzy pomiarów:** Michał Amborski i Jan Barabach (GC, GR). Zuzanna Palińska, Grzegorz Sokół i Martyna Gruszka (MG, NK).
- **Daty pomiarów:** 2021-09-11
- **Data pozyskania:** nieznane
- **Dodał do _RAW:** Paweł Gogolak
- **Licencja źródłowa:** nieznane
- **Kompletność:** Pięć plików SVX, cztery eksporty Qave i archiwum przekazania. Brakuje szkiców terenowych i opisów stacji.

## Zawartość

- `Lodowa_w_Ciemniaku.svx` — plik główny Survex (include + equate)
- `LwC_glowny_ciag.svx` — ciąg główny; zawiera fix UTM34 na stacji 0
- `LwC_gora.svx` — partie górne
- `LwC_Meander_Geografow.svx` — Meander Geografów
- `LwC_Nowy_Korytarz.svx` — Nowy Korytarz
- `Pomiary/` — oryginalne pliki eksportu DistoX2 (.cave)
- `Lodowa_w_Ciemniaku.zip` — archiwum materiałów źródłowych

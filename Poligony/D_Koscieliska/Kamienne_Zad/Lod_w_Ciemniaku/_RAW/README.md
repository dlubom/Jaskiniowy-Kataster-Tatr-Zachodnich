## Zawartość

- `Lodowa_w_Ciemniaku.svx` — plik główny Survex (include + equate)
- `LwC_glowny_ciag.svx` — ciąg główny; zawiera fix UTM34 na stacji 0
- `LwC_gora.svx` — partie górne
- `LwC_Meander_Geografow.svx` — Meander Geografów
- `LwC_Nowy_Korytarz.svx` — Nowy Korytarz
- `Pomiary/` — oryginalne pliki eksportu DistoX2 (.cave)

## Kompletność
Częściowa. Pomiary nie obejmują wszystkich opisanych partii: brak Ssaka,
Komory pod Lodem, partii górnych kominów ponad Wielkim Kominem.
